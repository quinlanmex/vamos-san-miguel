# Vamos San Miguel — Events Research

**Compiled:** mid-August 2026 (window: ~Aug 12 – late Sep 2026)
**Method:** WebFetch + web search of public SMA event sources. NO events invented — every row has a source URL that was actually read.

## Source notes
- **Biblioteca Pública taquilla** (`labibliotecapublica.org/taquilla/`) — **NOT fetchable as data.** The box office page is JavaScript-rendered; WebFetch returned only filter categories (Charla, Cine, Concierto, Danza, Festival, Presentación de libro, Taller, Teatro) and box-office hours ("open during events," Relox 50-A, Centro), with no actual listings. Its programming was instead picked up secondhand via discoversma.com and FASMA coverage (many Biblioteca/Patio Biblioteca/Quetzal Room events below).
- **discoversma.com/events** — richest usable source; provided most dated one-off and recurring listings.
- **mexiconewsdaily.com** + **theyucatantimes.com** — FASMA festival program details (dates/times/venues).
- **discoversma.com** event/venue pages — TOSMA market, El Charco tours, Grito de Dolores.
- Web search summaries of Teatro Ángela Peralta, markets, and Independence Day.
- Eventbrite / Bandsintown / allevents surfaced in search but were **not** used as primary date sources (aggregators, not read in detail).

Categories used: musica, cine, tours, comunidad, charlas, mercados, bienestar.
